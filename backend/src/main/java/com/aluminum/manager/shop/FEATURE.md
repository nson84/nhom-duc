# Ngữ cảnh và phạm vi hai cửa hàng

Đọc tài liệu này trước khi sửa code trong thư mục; cập nhật cùng thay đổi.

## Chức năng hiện có

`ShopContextFilter` cố định shop theo role vận hành, Admin có thể chọn; `ShopScope` hỗ trợ xem gộp và loại giao dịch nội bộ theo truy vấn.
